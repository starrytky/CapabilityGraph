# 2026-11-16

## 安装 oil-ui 设计技能

- 来源仓库：`oil-oil/oil-ui`（root 即技能，`SKILL.md` v0.33.5）
- 安装位置：`~/.workbuddy/skills/oil-ui`（用户级，2.2M）
- 安装方式：`npx skills add` 走不通，两个原因：
  1. `skills@1.9.0` CLI 支持的 agent 目标只有 cursor / claude-code / codex / gemini / opencode / windsurf / cline，**不认 workbuddy**，装完 WorkBuddy 扫不到；
  2. 该 CLI 用 `git clone https://github.com/...`，本机代理对这个 443 连接不稳定（`curl 28` 超时）。
- 实际做法：`codeload` tarball 下载 → 解压 → 复制整目录到用户级技能目录，删掉 `.github`。
- 依赖已核实：node v22.22.2（要求 22+）、Python 3.13（要求 3.10+）、本机 Edge/Chrome 可用。
- 冒烟测试：`node scripts/shoot.mjs design/prototype.html --out ... --size 390x844` 跑通，产出 page.png + report.json。

## 顺带发现的既有问题（尚未修）

oil-ui 的可读性 lint 对 `design/prototype.html` 报了三类问题，都是真问题：

- 文字对比度不达标 76 处（正文 <3:1、大字 <2.5:1），典型：`div.date`「11月16日 周一」2.81:1、`span.unit`「/ 100」2.81:1、`div.when`「刚刚」2.62:1；
- 小于 11px 的文字 2 处：热力日历月份标签「10月」「11月」10.5px；
- 多行正文行高过紧 2 处（1.20）：设计规范区的 `li`。

原因是我在稿子里把大量次要文字定成 `--muted`/`--faint` 的浅灰，视觉上轻，但低于无障碍下限。
