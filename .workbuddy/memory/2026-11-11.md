## 搭建 Ionic 8 + Angular 19 TodoList 项目（todo-app/）

- 位置：`angular-learn/todo-app/`；Node 20.11.1（nvm-windows 安装并 `nvm use`，但 PATH 里 WorkBuddy 自带 node 22 优先，需显式 `export PATH=/d/nvm/v20.11.1:$PATH`）
- 栈：Angular 19.2.25 + Ionic 8.8.19 + TypeScript 5.7，standalone + signals
- 功能：列表页（进度卡片/segment 筛选/勾选完成/滑动删除/FAB 弹窗新增）+ 详情页（`withComponentInputBinding` + `input.required<string>()`、编辑/删除/完成切换）；TodoService signal + localStorage（key `ionic-angular-todos-v1`）
- 关键配置：`provideIonicAngular({ mode: 'ios' })`；Ionic 核心 CSS 在 angular.json styles 中按 core→normalize→structure→typography→dark.system→theme→styles 顺序注入（不走 SCSS @import，避免 exports 解析问题）
- 踩坑：
  1. npmmirror 对大包（@rspack/core 等）元数据 >60s 超时，换官方源 `--registry=https://registry.npmjs.org` 解决
  2. Ionic `fill="outline"` **只有 MD 模式有边框样式**，iOS 模式没有 outline CSS；解法：input/textarea 单独 `mode="md"`
  3. Edge headless 在 Windows 有 ~500px 最小窗口宽度，`--window-size` 更小时截图是"500px 布局被裁到请求宽度"→ 假溢出；DOM 检查 + 宽度对照可证伪
  4. `ion-item` 没有 fill 属性；ion-item-sliding 内 checkbox 需外层 div `(click)="$event.stopPropagation()"` 防止触发 item 路由
- 验证：ng build 通过（initial 963kB，budget 调至 1.2MB/2MB）；headless 截图验证两页渲染正常
- 预览图：根目录 `app-preview-list.png`、`app-preview-detail.png`；dev server 于 127.0.0.1:4200
