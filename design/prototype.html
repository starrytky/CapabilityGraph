7 屏，390×844，浅色主题。数值沿用设计文档里的示例计算：事件循环节点掌握度 26，当日分 84。颜色只承载「难度层」与「分数档位」两种语义，其余全部用中性灰。

三个 Tab：今日 / 地图 / 我的 分数色阶 5 档（无红色） 难度层 D1–D4 触控目标 ≥44×44

设计规范

色彩

页面底色#F4F3EF
卡片#FFFFFF
主文字#1F1E1C
次要文字#6B6A66
分数 0–29#DCD9E6 仅作底色
分数 30–49 / D1#AFA9EC
分数 50–69 / D2#7F77DD
分数 70–84 / D3#534AB7
分数 85–100 / D4#3C3489
提醒（门禁/逾期）#BA7517

低分不用红色。红色会把「还不会」编码成「做错了」，而这个产品里还不会才是常态。分数只用同一色相的深浅表达，且必须同时给出文字档位（强证据日），不靠颜色单独承载信息。

字体与节奏

分数84px / 500 / 字距 -3px / tabular-nums
节点掌握度44px / 500 / tabular-nums
页面标题17px / 500
区块标题15px / 500
正文13px / 400 / 行高 1.8
辅助12px / 400 / 次要色

间距一律 4 的倍数：卡片内边距 13–14，区块间距 24，列表项 10。圆角：卡片 12 / 大卡 20 / 手机框 36。数字全部用等宽数字，避免分数跳动时宽度抖动。

动效

  • 分数跳变 420ms cubic-bezier(.2,.8,.2,1)，数字滚动而非替换
  • 来源浮层 入 180ms 上移 4px，停留 2.4s，出 240ms 淡出
  • 卡片置灰 160ms，完成后 1 次轻微缩放 0.98 → 1
  • 地图展开 高度 200ms，不使用弹簧效果
  • 全部动效在 prefers-reduced-motion 下退化为直接切换

    • 整个产品只有一处动效值得花力气：分数变化。它必须在 400ms 左右完成、并伴随来源浮层。省掉它，产品就退化成一块冷冰冰的仪表盘。

    文案

  • 五档：还没变成能力 / 都在概念层 / 有实打实的进展 / 强证据日 / 结构级进展
  • 禁止「你太差了」「又断了」「击败了 xx% 的用户」
  • 把「你答错了」改为「这里我没听懂，能换个说法吗」
  • 把「失败」改为「这组还不够」
  • 所有分数变化都要能追到一句具体的话，例如「+8 来自 修了 setTimeout 顺序 bug」

    • 无障碍

  • 正文对比度 ≥ 4.5:1，大号数字 ≥ 3:1
  • 可点击区域 ≥ 44×44，卡片整块可点
  • 分数不单独依赖颜色 — 必须同时有文字档位
  • 进度条全部带 role="meter" 与可读值
  • 动效遵循 prefers-reduced-motion

    • 这条不只是合规：产品里「可访问性」是六大能力区之一，自己的界面不过关说不过去。

    这版故意没做的

  • 排行榜、好友、公开主页
  • 连续打卡徽章、断签提醒
  • 内容推荐流、视频课入口
  • 任何付费墙或功能锁
  • 深色模式（等交互稳定后再做，避免两套维护）

    • 前四项不是排期靠后，是设计上拒绝。它们会把产品推向它打不过的战场，或污染分数的可信度。
